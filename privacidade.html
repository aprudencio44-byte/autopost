Política de Privacidade

Última atualização: 17 de novembro de 2026

Esta política explica como o Finance Autopost usa os dados das contas conectadas a ele.

Dados acessados

Com a sua autorização, a ferramenta acessa pela API do YouTube:

  • permissão para enviar vídeos ao seu canal;
  • dados públicos e estatísticas dos vídeos do seu canal (visualizações, curtidas, retenção e tempo assistido).

Como os dados são usados

Os dados são usados só para publicar os vídeos criados pela ferramenta e para medir o desempenho deles. As estatísticas ajudam a escolher os próximos temas.

Armazenamento

O token de acesso e as estatísticas ficam guardados apenas no computador do dono da ferramenta. Nada é vendido, compartilhado ou enviado a terceiros, exceto às próprias plataformas onde os vídeos são publicados.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta também usa os Serviços de API do YouTube e segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como remover o acesso

Você pode retirar o acesso a qualquer momento em myaccount.google.com/permissions. Depois disso, a ferramenta não consegue mais publicar nem ler dados do canal.

Contato

Dúvidas: use o e-mail de suporte exibido na tela de autorização do Google.
